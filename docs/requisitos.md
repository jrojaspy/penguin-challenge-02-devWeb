# Requisitos del challenge

## Funcionales
- [x] Inicio: qué es la app, problema que resuelve, CTA a proveedores
- [x] Proveedores: tarjetas con nombre, categoría, calificación visual, acción
- [x] Datos desacoplados (JSON + fetch), nunca hardcodeados en HTML
- [x] Estados: cargando, sin resultados, error
- [x] Tercera página funcional (Detalle de proveedor)

## No funcionales
- [x] Una sola estrategia de estilos (CSS con variables + BEM)
- [x] Responsive, contraste AA, teclado, labels claros
- [x] Código organizado

## Proceso y entrega
- [X] Lighthouse: 2+ mejoras con evidencia
- [X] 5 pruebas con personas + 1 mejora aplicada
- [x] CHANGELOG.md, README (ejecutar, desplegar, Lighthouse)
- [X] Sitio desplegado + repositorio GitHub

## Historias de usuario
1. Como visitante quiero entender qué hace la app en 5 segundos.
2. Como usuario quiero ver proveedores con su calificación para comparar.
3. Como usuario quiero filtrar por categoría y nombre para ir rápido.
4. Como usuario quiero abrir un perfil y llamar al proveedor.
5. Como usuario con mala conexión quiero un mensaje claro y poder reintentar.
