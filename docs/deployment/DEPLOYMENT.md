# Deployment

## Reto 02 — ServiPy

Versión destinada a pruebas de usabilidad.

## Plataforma

GitHub Pages.

## Tipo de aplicación

Aplicación web estática construida con:

- HTML;
- CSS;
- JavaScript;
- JSON como fuente de datos.

No requiere proceso de compilación.

## Fuente de publicación

Repositorio:

`penguin-reto-02-services`

Rama:

`main`

Carpeta:

`/(root)`

## Configuración

En GitHub:

1. Abrir el repositorio.
2. Entrar en `Settings`.
3. Seleccionar `Pages`.
4. En `Build and deployment`, seleccionar:
   `Deploy from a branch`.
5. Seleccionar:
   `main`.
6. Seleccionar:
   `/(root)`.
7. Guardar.

## Archivos principales publicados

- `index.html`
- `providers.html`
- `detail.html`
- `css/styles.css`
- `js/providers.js`
- `js/detail.js`
- `data/providers.json`

## URL pública

Pendiente de completar después de habilitar GitHub Pages:

`https://USUARIO.github.io/penguin-reto-02-services/`

## Verificación previa a pruebas

Antes de entregar la URL a los evaluadores verificar:

- Inicio carga correctamente.
- CSS se aplica.
- Proveedores aparecen.
- JSON carga correctamente.
- Filtro funciona.
- Detalle funciona.
- `detail.html?id=1` muestra un proveedor.
- Botón de contacto funciona.
- Sitio funciona en móvil.
- Sitio funciona en tablet.
- Sitio funciona en escritorio.

## Versión de evaluación

Los cinco participantes deben utilizar la misma URL pública.

No se deben realizar modificaciones en producción durante la ronda de pruebas, salvo que exista un error crítico que impida completar la tarea.
