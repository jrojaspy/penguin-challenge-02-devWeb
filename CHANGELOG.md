### Added

- Enlace "Saltar al contenido principal".
- Indicadores de foco visibles.
- Región de estado accesible para contador de resultados.
- Texto de ayuda asociado al filtro.
- Uso de `aria-busy` durante cargas dinámicas.
- Etiquetas accesibles para estado, rating y acciones.
- Checklist documental de accesibilidad.
- Soporte ampliado para `prefers-reduced-motion`.

### Changed

- Se reforzó el contraste del texto secundario.
- La navegación activa utiliza `aria-current`.
- Los enlaces de navegación tienen mayor área interactiva.
- El enlace de regreso tiene mayor área táctil.
- Los estados de disponibilidad incluyen información textual.
- El filtro incluye descripción accesible.

### Fixed

- Orden y claridad de navegación mediante teclado.
- Falta de alternativa para saltar navegación repetitiva.
- Dependencia visual del color para algunos estados.
- Compatibilidad del indicador de foco con navegadores móviles.
